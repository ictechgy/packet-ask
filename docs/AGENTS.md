# 문서 규약

`docs/` 아래에서 활성화된다. 루트 [AGENTS.md](../AGENTS.md) 를 먼저 읽는다.

## design.md 가 계약이다

[design.md](design.md) 의 "실행 경계" 는 번호 매긴 불변식 목록이고, 이
저장소에서 가장 권위 있는 설계 문서다.

- 동작을 바꾸면 **해당 번호를 고치거나 새 번호를 뒤에 붙인다.** 번호를
  재사용하거나 중간에 끼워 넣지 않는다. 커밋 메시지와 PR 이 번호로 서로를
  가리킨다.
- 불변식은 하는 일뿐 아니라 **하지 않는 일**을 같이 적는다. "OS sandbox 는
  아니다", "증명하지 않는다" 같은 문장이 그것이다. 지우지 말 것.
- `hardening.md` 와 `runtime-hardening.md` 는 배치별 설계 노트다. 현재형으로
  쓰여 있으니 동작이 바뀌면 낡은 문장을 고친다.

## 과잉 약속 금지

이 저장소는 **줄인 것만 주장하고 막았다고 주장하지 않는다.** 문서를 쓸 때
가장 자주 저지르는 실수다.

- "유출이 없다", "학습되지 않는다", "샌드박스" 라고 쓰지 않는다.
- 기전이 무엇을 하는지와 **무엇에 대해 아무 말도 하지 않는지**를 같이 적는다.
- 실측하지 않은 것을 실측한 것처럼 쓰지 않는다. 추측이면 추측이라고 밝힌다.
- 실제 사례: "stdin 을 쓰면 셸 히스토리에 남지 않는다"는 틀렸다. 대화형
  셸은 heredoc 본문을 히스토리에 기록한다. 정확한 성과는 argv 와 프로세스
  목록에서 빠진다는 것뿐이었다.

## 언어

- 기본은 영어다. `README.md`, `SECURITY.md`, CLI 메시지, 번들 `SKILL.md`.
- 한국어 대응본은 `README.ko.md`, `SECURITY.ko.md` 로 따로 둔다.
- **`README.md` 와 `SECURITY.md` 에 한글이 들어가면 테스트가 실패한다.**
- `docs/` 안의 설계 문서와 `CONTRIBUTING.md` 는 한국어다.
- 영어 문서와 한국어 문서를 같이 고친다. 한쪽만 고치면 계약이 갈라진다.

## 사용자에게 보이는 표면을 바꿨다면

기능을 더했는데 아래를 안 고치면 아무도 못 쓴다.

| 바꾼 것 | 같이 고칠 곳 |
| --- | --- |
| CLI 플래그·동작 | `README.md`, `README.ko.md`, `docs/design.md` |
| 신뢰 경계·한계 | `SECURITY.md`, `SECURITY.ko.md` |
| MAIN 이 알아야 할 것 | `src/packet_ask/data/SKILL.md` |
| 환경 변수 | `SECURITY.md` 변수 표, `.env.example` |

번들 `SKILL.md` 는 특히 잊기 쉽다. 0.4.0 의 `--line-numbers` 와
`--selected-tree` 는 배포하고도 스킬에 없어서 MAIN 이 존재를 몰랐다.
